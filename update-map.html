Update the pledge map

For the MoveYourWayIA team. This page turns the Microsoft Forms responses into county totals for the website map. Your file never leaves this computer: only the 99 county counts are saved, with no names, emails or pledge text.

Step 1 · Download the responses

  1. Open the pledge form in Microsoft Forms and click the Responses tab.
  2. Click Open results in Excel (or ⋯ → Download a copy). Save the file.

Step 2 · Choose that file

Step 3 · Save the county totals

Step 4 · Put it on the website

  1. Open the website’s data folder upload page on GitHub (sign in if asked).
  2. Drag pledge-counts.csv onto the page. It replaces the old file.
  3. Click the green Commit changes button. The map updates in a minute or two.
